## What I'm doing now

**Lead Frontend Developer - Ecommerce Empire**

- Led the architectural migration of the CRM frontend from a Layer-based structure to Feature-Sliced Design (React + MobX retained, MVVM within slices) - a cross-product initiative to unify code organization and ease developer rotation between teams. Designed a custom AI-assisted pipeline (Analyst - Developer - QA - Reviewer stages on Claude CLI with manual review between stages), generated and refined a 36-task plan, and implemented the tasks sequentially, cutting the effort to ~48 engineering hours.
- Built the frontend integration with internal AI services together with the AI team: token authentication, request/response handling, and embedding AI results into existing CRM workflows.
- Developed an i18n system supporting 4 languages with in-place translation editing via an admin panel - content managers update text without a frontend release.
- Lead a frontend team of 3 developers (2 juniors I personally onboarded and mentored): task breakdown, code review, and architectural decisions. Introduced review and PR standards the team now follows by default.
- Built a library of 20+ modal components preconfigured for common CRM patterns (entity editing, confirmations, multi-step forms) - reduced duplication and standardized modal UX across the platform.
- Designed a shared access-control layer (RBAC) and, on top of it, implemented UI flows and access rules for 3 of the platform's 8 roles (moderator, admin, freelancer), moving permission checks from scattered code into a single layer.
- Migrated from MUI DataGrid to AG Grid Enterprise for capabilities MUI lacked: custom cells, server-side row model, grouping and aggregation, advanced sorting and filtering.
- Initiated the UI-stack migration from MUI + TSS React to Ant Design - sped up feature development thanks to a richer ready-made component base and replaced a heterogeneous custom CSS-in-JS layer with a single UI kit.
